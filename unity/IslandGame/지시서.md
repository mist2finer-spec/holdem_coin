# Unity 에이전트 지시서

## Pink Glass 공격 모션 참조

Windows 작업 PC에서 사용하는 로컬 원본 폴더입니다.

```text
G:\new_project\attack_motion_ref\pink-glass-attacks-v4
```

1. 모션 작업을 시작할 때 로컬 PowerShell에서 아래 명령으로 폴더를 확인합니다.

   ```powershell
   Test-Path -LiteralPath 'G:\new_project\attack_motion_ref\pink-glass-attacks-v4' -PathType Container
   ```

2. 폴더에 접근할 수 있으면 `animation-index-v4.csv`가 있는지 확인합니다. 인덱스가 있으면 액션 이름과 `folder`, `loop` 열을 참고해 FBX 위치와 반복 설정을 찾습니다. 인덱스가 없으면 폴더 안에서 FBX를 검색합니다. 폴더 구조와 파일명은 로컬에서 확인합니다.
3. 실제 Unity 적용 요청이 들어오면 필요한 FBX만 `unity/IslandGame/Assets` 아래의 적절한 위치로 가져옵니다. 원본 폴더는 참조용으로 유지합니다.
4. 로컬 폴더에 접근할 수 없으면 실행 환경에서 `G:` 드라이브에 접근 가능한지 확인하고, 필요한 경우 작업 PC의 실제 경로를 요청합니다.

이 문서는 로컬 참조 경로를 기록합니다. Unity 임포트와 재생은 적용할 때 확인합니다.
