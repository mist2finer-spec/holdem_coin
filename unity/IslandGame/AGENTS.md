# Unity 범위 규칙

저장소 공통 진입은 [루트 AGENTS](../../AGENTS.md), 최신 분기 상태는 [CURRENT](../../docs/agents/CURRENT.md)를 따른다. 여기서는 선택한 역할만 유지한다.

- 작업 프로젝트는 이 저장소의 `unity/IslandGame`이다. 로컬 실행 중인 Editor의 실제 경로·브랜치를 확인하고 다른 worktree의 Editor를 조작하지 않는다.
- 일반 구역 Side25D, 보스전 QuarterView를 유지한다. 현재 게임 브랜치의 10구역은 사이드뷰 입장→보스 등장/쿼터뷰→바위 하강→마을 진입이다. main의 이전 맵 흐름과 혼동하지 않는다.
- 이동 경로·전투 타이밍·맵·캐릭터 액션·홀덤을 요청 없이 바꾸지 않는다. 원본 씬과 프로젝트 전체를 덮어쓰지 않는다.
- Spine 4.2 데이터/런타임 호환성을 유지한다. 스킬을 Assets에 넣거나 기존 스킬을 덮어쓰지 않는다.
- 기본 액티브 6칸의 창고 소유와 장착 상태를 구분한다. 젬 제거 시 아이콘/시전은 비활성, 슬롯 번호는 유지한다.
- 로컬 마을길/무보상 보스 훈련과 서버의 계정·보상·저장 권한을 구분한다. Unity/웹 기능과 UI가 동일하다고 가정하지 않는다. 영구 DB 저장 방식 도입은 보류 상태다.
- 실제 수정 시 Console→컴파일→관련 Play Mode 순으로 검증한다. 설치·연결·컴파일·프레임 진행·렌더·Android 실기를 별개로 보고한다.
- 임시 조명·씬 활성화·runInBackground·검사용 틱은 검증 뒤 복구한다. 사용자의 열린 Editor를 편의상 종료하지 않는다.
- [UNITY_HANDOFF_KO.md](UNITY_HANDOFF_KO.md)는 필요할 때 관련 날짜/제목만 검색한다. 예: `rg -n '도트|카메라|보스' unity/IslandGame/UNITY_HANDOFF_KO.md`. 전체 이력은 시작 필수 문서가 아니다.
- 동시성/핵심 계약 문제가 아니면 형식 검증 대신 관련 기존 회귀를 사용한다. 자세한 기준은 [WORK_RULES](../../docs/agents/WORK_RULES.md).
