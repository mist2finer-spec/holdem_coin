# Hong standing poker sprites

Built-in image generation tool, transparent output. Inputs: public/island/hong.png
(identity/outfit), reference-layout.png (tiny chibi poker pose/style only).
No CLI/API key was used. Sheet saved as hong-table-source.png, extracted by
scripts/prepare-hong-table.py. Runtime sprite cells stay RGBA with original alpha.

Prompt:
Create a production game sprite sheet for HONG, the adult black-haired woman in image 1, matching the tiny chibi poker guests in image 2. IMAGE 1 is identity/outfit reference, IMAGE 2 is style/pose reference ONLY. Exactly FOUR separate full-body 3-head-tall chibi sprites on a TRUE TRANSPARENT background, laid out in a strict 2x2 grid with equal square cells and generous padding, each sprite centered in its own quadrant. TOP LEFT: front-facing, standing, looking ahead, both bent elbows forward and palms resting flat on an invisible tabletop at chest/waist height. TOP RIGHT: right-facing profile/three-quarter side, standing, leaning gently forward, both hands extended toward an invisible table on her RIGHT. BOTTOM LEFT: left-facing profile/three-quarter side, standing, both hands extended toward an invisible table on her LEFT. BOTTOM RIGHT: rear-facing standing, long straight black hair falling as a single curtain down her back, hands extended forward toward an invisible tabletop above her. All FOUR views are of the SAME character: dark charcoal straight long hair, dark eyes, blunt bangs, black sleeveless high-neck cropped top, short black pleated skirt, black detached forearm sleeves, thigh-high dark stockings, brown-black ankle boots. Cute clean detailed 2D game sprite/pixel-inspired edges, consistent proportions and lighting, no perspective ground, no shadows cast on background. Keep all hands, feet and hair inside each cell, no cropping. NO chairs, NO tables, NO weapons, NO cards, NO text, NO labels, NO panel borders, no extra people. Pose-ready isolated sprites, crisp outlines, modest neutral standing poker pose.
