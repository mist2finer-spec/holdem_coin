- 개별 PNG 3,902개, TextAsset 340개, OBJ 292개, 폰트 1개: 추출 파일 4,535개입니다.
- Spine 세트 170개 / 편집용 영역 PNG 4,526개 / 원본 포함 갤러리 이미지 8,428개입니다.

- 0×0 크기의 빈 Font Texture 1개는 이미지가 없는 런타임 리소스입니다. `empty_runtime_texture`로 명시했습니다.
- 생성된 PNG 전체를 Pillow로 실제 디코딩했습니다. 이미지 일부가 잘린 경우 원본에서 재추출하고 원본 기록의 SHA-256과 일치하는지 확인했습니다.
- 소규모 번들 2개를 새 출력 경로에 재추출하는 스모크 테스트도 통과했습니다.

## 애니메이션 호환성 참고

실제 Spine 4.2.120 런타임으로 170개 스켈레톤을 읽고 애니메이션을 샘플링했습니다. 169개 세트는 검사를 통과했습니다. `Enemy_DemonEye_01`의 `rest1/chain02` 물리 본은 비유한 좌표를 생성했습니다. 해당 세트는 문제 발생 이후의 애니메이션 검사를 중단했으므로 전부 호환된다고 표시하지 않았습니다.

이미지와 원본 스켈레톤은 수정하지 않았습니다. 이 캐릭터를 웹에서 사용할 때 물리 제약 설정·초기화·런타임 버전을 따로 검토하세요. 이는 추출 파일의 손상이 아니라 이 검사 조건에서의 실행 호환성 기록입니다. [기계 판독 결과](catalog/spine-runtime-validation.json)를 참고하세요.

`asset_tool.py verify`는 파일 무결성 검사이며, `check-library-spine.mjs`는 이 호환성 경고로 exit(1)을 반환합니다. 물리 연산에 대한 시각적 QA나 모든 스킨 조합 검사는 수행하지 않았습니다.
