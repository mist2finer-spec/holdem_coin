# 역할 간 전달

지정된 담당자가 직접 진행한다. Tier는 책임과 협의 관계이며 매 작업마다 총괄/리드 승인을 추가하는 절차가 아니다. 다른 역할의 코드가 필요한 때만 그 경계와 필요한 결과를 전달한다.

수신자 1명당 아래 내용을 짧게 작성한다. 여러 역할이면 공유 근거를 복제하지 않고 링크한다.

```text
수신 역할:
사용자 목표 / 이번 범위:
branch + SHA / 확인 일시:
관련 파일·심볼 (최대 5개):
관찰된 사실 (출처 또는 evidence ID):
추론 / 아직 모르는 것:
제안 변경 / 유지할 조건:
완료·검증 기준:
증거 위치 / 다음 담당자:
```

- 큰 소스·대화·로그를 붙이지 않는다. 필요하면 증거 ID와 offset/행 범위를 전달한다.
- 첫 파일 묶음이 부족하면 담당자가 근거를 남기고 범위를 확장한다.
- 실패 패킷은 최소 재현 입력, 기대/실제, 플랫폼, 오류 구간을 포함한다.
- 준비 요청의 결과는 준비 완료와 미확인 사항까지다. 담당자 전달이 구현·생성·배포의 추가 허가는 아니다.
- 병렬 에이전트를 실제 사용할 때만 파일/작업본 소유를 나눈다. 읽지 않은 결과를 검증 완료로 합치지 않는다.
