# 1.23.0: 시작 패 배분과 쇼다운 표시

이 규칙은 일반 공정 무작위 홀덤 배분과 다르다. 사용자 요청에 따라 온라인 게임의 프리미엄
시작 패 빈도를 낮추는 하우스 룰이며 로비에서 인간/CPU의 차등 확률을 공개한다.
프리미엄은 JJ/QQ/KK/AA 및 AK 수티드/오프수트다. AQ, TT, 기타 브로드웨이와 커넥터는 포함하지 않는다.

| 대상 | 표준 확률 | 새 목표 확률 | 상대 감소율 |
| --- | --- | --- | --- |
| 인간 플레이어 | 40/1326 = 3.0166% | 2.4133% | 20% |
| CPU | 40/1326 = 3.0166% | 2.7149% | 10% |

각 좌석에서 먼저 목표 확률로 프리미엄/일반 그룹을 선택하고, 남은 덱의 해당 그룹 내에서는
균등하게 두 장을 선택한다. 버튼 다음 좌석부터 순회한다. 선택한 카드는 반드시 덱에서 제거한다.
프리미엄 조합이 소진되면 불가능한 패를 만들지 않고 일반 그룹에서 선택한다.
이는 전체 재딜 횟수 제한이나 잦은 좋은 패에 대한 사후 교체가 아니며, 특정 상대의 패/결과/스택을
보아 승패를 정하지 않는다. 단기 표본에서 20%/10% 감소를 보장하는 쿼터도 아니다.

프리미엄 배분 후 남은 덱 순서는 유지한다. 플랍/턴/리버와 번 카드를 미리 살펴 재추첨하지 않는다.
단, 홀카드 분포가 바뀌면 남은 카드 구성과 보드의 주변 분포도 간접적으로 변한다.
포스트플랍 메이드 핸드 전체 빈도나 실제 승률을 20%/10% 낮춘다는 뜻은 아니다.
보드/평가기/사이드팟/레이크/승리 확률에는 직접 보정을 가하지 않는다.
봇의 기존 range 기반 EV는 근사 모델을 유지한다. 이 비표준 공동 배분 분포 전체를 정확하게
적분하는 솔버는 아니며, 공개 행동 기반 상대 모델과 계속 대조해야 한다.

싱글과 서버 모두 `dealStartingHands`를 사용한다. 기존 `makeDeck`의 Fisher–Yates는 유지하고,
학습/에퀴티 샘플링에 하우스 배분을 일괄 적용하지 않는다.
서버 핸드 JSON/CSV에 dealingProfile과 두 multiplier를 기록하며 공개 export에도 설정만 포함한다.
종전 기록에는 이 필드가 없고 새로 생성된 핸드부터 적용된다.

이번 변경에서는 기존 전략/참여 게이트를 추가 수정하지 않았다.

133번: 보드 6♦/4♥/J♠/A♦/8♠, AK는 A 원페어로 홀카드 2+보드 3장,
93은 A 하이로 홀카드 1+보드 4장을 사용한다. 각각 최선의 5장이며 서로 다른 보드 장수는 정상이다.
정산은 팟 9,480, 레이크 474, 지급 9,006으로 일치했다.
UI는 모든 행에 홀카드 수+보드 수=5장을 표시하고 사용하지 않은 홀카드는 흐리게 유지한다.
