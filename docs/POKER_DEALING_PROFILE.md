# 1.24.0: 페어·수딧·커넥터 억제 배분

싱글과 서버는 `src/lib/poker-deal.ts`의 공통 배분 함수를 사용한다. 이는 일반 홀덤의 공정한 균등 셔플과 다른 공개 하우스 룰이다. 로비 안내와 핸드 JSON/CSV에 프로필을 기록한다. 과거 1.23.0의 인간 JJ+/AK 20%/CPU 10% 별도 보정은 교체되며 중첩되지 않는다.

## 현재 정책

| 두 장의 특성 | 억제 강도 | 조합의 상대 가중치 |
|---|---:|---:|
| 같은 랭크 페어 | 0.60 | 0.40 |
| 같은 무늬 | 0.50 | 0.50 |
| 랭크 차이 1 또는 2, 혹은 A2 | 0.40 | 0.60 |
| 해당 없음 | 0 | 1.00 |

플레이어/CPU, 스택, 포지션에 따라 가중치를 바꾸지 않는다. 조건이 겹치면 가장 높은 억제 강도만 적용한다. A2는 연결로 취급하지만 A3는 별도로 포함하지 않는다. `Card.rank`에서 랭크를 계산하므로 존재하지 않는 `Card.value`에 의존하지 않는다.

제안의 반복 재추첨/덱 재셔플 대신 남은 덱의 모든 두 장 조합에서 가중 추출한다. 무한 재추첨이나 5회 후 무조건 통과 분기가 없다. 어떤 합법 조합도 가중치가 0이 되지 않는다. 선택한 카드만 제거하고 나머지 덱 순서는 유지한다. 미래 보드·승자·상대 홀카드를 이용한 결과 맞추기는 하지 않는다. 좌석 배분 순서는 버튼에 따라 회전한다.

**억제 강도는 최종 출현율 감소 비율이 아니다.** 가중치 정규화 및 앞선 좌석에서 빠진 카드에 따라 최종 확률이 달라진다.

52장 기준 첫 배분 좌석의 이론 확률은 페어 3.0952%, 수딧 15.4762%, 커넥터/원갭/A2 21.9048%이다. 균등 배분은 각각 5.8824%, 23.5294%, 28.9593%다. 따라서 정확히 60/50/40% 줄어든다고 표시하지 않는다.

결정론적 시드 20,000개 6인 테이블(120,000개 시작 패)의 관측값은 페어 3.1058%, 수딧 15.43%, 커넥터 21.6225%였다. 다른 시드는 변동한다. 첫 좌석은 이론값 허용 오차를 검사하며, 실제 인간/CPU 표시를 모두 바꿔도 동일 시드의 결과가 같음을 검증한다.

## 규칙/로그

블라인드, 액션 합법성, burn/보드 진행, 승자 판정, 사이드팟, 레이크는 이 변경과 별개다. 카드 객체는 기존 `{rank,suit}`를 유지한다. 프로필 ID는 `paced-textures-v2`이며 `LIVE_RULES.version`은 `1.24.0`이다. 6/8인 덱 보존, 입력 순서 독립성, 상수 RNG 종료, A2/원갭, 조건 중첩을 회귀 검사한다.

기존 Hand #133의 보드 3장 대 4장 사용 차이는 합법적인 최선의 5장 구성이다. 승패별로 사용하는 홀카드 개수가 달라질 수 있으며, 이번 배분 변경과 별개다.
