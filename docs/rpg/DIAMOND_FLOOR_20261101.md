# 깊이가 보이는 마름모 포장 바닥

현재 기본 `/hunt` Rogue 미궁의 바닥 표시를 얇은 수평선/플랫폼 단면에서 연속된 마름모 돌 포장 면으로 변경했다. 이식 기준은 사용자가 제공한 바르디안 전투 화면의 얕은 2.5D 바닥이다. 원본 그림을 그대로 추출한 텍스처라고 주장하지 않는다.

- `rogue/floor-surface.ts`: 72×24 월드 유닛의 마름모 타일, 행마다 반 칸 엇갈림. 같은 월드 타일에 같은 색/금이 표시되고 카메라 이동으로 재생성되지 않는다.
- 캐릭터의 기존 발 위치를 기준으로 뒤쪽52, 앞쪽 최소52 월드 유닛의 시각 깊이. 앞쪽 포장은 전투 창 하단까지 연장해 벽이 바닥 아래에 드러나지 않게 한다.
- 4개 방 테마별 암석 팔레트, 뒤쪽 접합부 그림자, 타일 가장자리의 약한 하이라이트. 좁은 뷰에서도 타일 깊이가 보인다.
- 벽/횃불/기둥/석상은 뒤쪽 바닥 경계에 정렬. 잔해는 바닥 안쪽에 배치. 플레이어·적·체력바·장판 경고는 바닥 뒤가 아니라 기존 렌더 순서로 표시된다.
- 바닥은 각 방 가로 경계에서 자른다. 실제 통로/구덩이·발판은 기존 게이트 렌더러를 유지한다.

플레이어 및 몬스터 좌표, X축 조작, 발 접지 기준, 충돌, 점프·슬라이딩·낙하 판정과 맵 생성 규칙은 변경하지 않았다. 원근감은 시각 표현이며 상하 자유 이동이나 새로운 지형 판정을 추가하지 않는다. 레거시 별도 캠페인 렌더러는 이번 변경 대상이 아니다.

검증: 타입 검사, 운영 빌드, 미궁 회귀56건 통과. 실제 조립 함수를 이용해 4개 테마를 렌더링하고 타일 이어짐·바닥 범위·소품 접지를 확인했다. 재현: `node --import ./mini-services/poker-server/node_modules/tsx/dist/loader.mjs scripts/rpg/render-dungeon-floor.ts` (기본 출력 `/tmp/rpg-diamond-floor-preview.png`). UI/그림 변경이며 직접 렌더 및 기존 지형 테스트로 충분해 형식 검증은 생략했다.
