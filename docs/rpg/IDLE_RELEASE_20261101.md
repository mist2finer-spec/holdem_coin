# 방치 성장·실물 장비·젬 연결 업데이트

## 플레이 흐름

사냥 → 장비·소환 → 장비/소환/골드 성장/특성. 무기·갑옷·장갑·장화·반지1·반지2에 실제 보유한 젬을 넣는다. 첫 칸은 액티브, 나머지는 보조다. 같은 젬 복사본은 인벤토리 전체에서 동시에 두 번 쓸 수 없다. 아이템에서 빼면 보관함 수량을 소모하지 않고 다시 사용할 수 있다.

새 계정은 기본 액티브6종과 일반 장비6개, 시험용 영혼석1,000개로 시작한다. 나머지29액티브/30보조는 소환과 마일리지 교환으로 획득한다. 이전 플레이어는 실제 선택해 사용하던 젬 복사본과 과거 빌드를 보존하며, 예전 올 컬렉션 UI가 모든 젬을 실물로 지급했다는 뜻은 아니다.

매일 회수하는24시간 적립을 기준으로 50P32.13일,55P43.39일,60P57.06일. 이는 시작12포인트를 포함한 공용 트리 포인트이며 특성은 별도로 레벨업당1포인트다. 골드 성장과 장비 강화는 별도 유지한다. 기존 스킬 레벨·숙련도·투혼은 운영 성장 계산/UI에서 제외하고 과거 필드는 보존한다. 레벨은 복원된 원본 곡선을 따르며 트리 상한90포인트 이후에도 레벨/골드 성장이 계속된다. 유료 결제/가속 판매는 구현하지 않았다.

## 전투 및 시너지

양 엔진이 같은 동결 CompiledBuild를 사용한다. 실제 장비 소켓, 내장 보조, 군주얼/헌신 옵션, 발동 보조 큐, 방어 스킬과 다중 오라가 연결된다. 홍 이외8캐릭터는 시작 고유 코어 데이터와 Forbidden 대여/어시스트 초상 연출에 사용하며, 플레이 선택은 아직 홍만 가능하다. 기존 홍의 검·도끼·쌍검·창 에셋이 실제 장착 무기에 따라 바뀐다.

## 적용 범위와 남은 일

- 장비 등급6단계/등급별 링크 제한·물리 젬 소유권·소환은 적용.
- 골드 능력치/레벨 특성·24시간 방치 적립은 적용.
- 홀덤 서버 캐시게임의 실제 순이익 승리 보상, 플러시 이상 시드 변경권, 주간10승 초월석 및 보스 단계 첫 처치 초월석을 연결. 싱글 클라이언트의 승리 신고로 보상을 주지는 않는다.
- 일반 주얼→고유 주얼 초월, 직접 몬스터 젬 확률 드롭, 유료 가속, 캐릭터8종 플레이어블과 전용 어시스트 모션은 이번 범위에서 미적용. 현재 젬 획득은 소환·홀덤 마일리지로 제공한다.
- 장갑/장화 등 새 액세서리 계수·6등급 배율·소환 확률/가격은 자체 설계다. 원본 서버 확률 복원으로 표시하지 않는다.
- SQLite 원자적 정산과 같은 파일에서의 프로세스 재시작 보존은 검증했다. 현재 Render Free의 배포 간 보존은 **미완료**다. 필요한 유료 디스크 구성/백업·복원 절차는 `docs/operations/IDLE_PERSISTENCE.md`에 있다.

세부 근거: `IDLE_EQUIPMENT_BALANCE_20261101.md`, `EQUIPMENT_COMBAT_20261101.md`, `IDLE_PERSISTENCE_TESTS_20261101.md`.
