# 하이브리드 미궁 성장 적용

## 운영 범위

현재 기본 사냥터인 횡스크롤 촛불 미궁(RogueEngine)에 적용한다. 기존 원본 캠페인(HuntEngine)의 스테이지/몬스터 테이블은 유지한다. 캐릭터 계정 레벨과 미궁 난이도는 별도다. 신규 계정은 캐릭터1레벨/미궁1레벨이며 기존 계정의 레벨·훈련·장비·젬을 초기화하지 않는다. 기존 저장에 미궁 진행이 없다면 미궁만1로 추가한다. 실제 탈출 성공을 커밋하면 다음 난이도가 열리고 다음 런에 적용된다. 패배·새 맵 시드·재접속은 난이도를 올리지 않는다.

전투 수치·골드·EXP·특성의 공식과 시뮬레이션은 `HYBRID_BALANCE_20261101.md` 및 `hybrid-balance-simulation-20261101.json`이 기준이다. 원본 복원 부분(능력치 상대 공식/훈련 비용/레벨 비용)과 자체 설계(몬스터 성장계수/저항/구역 팩/보상 상한)를 구분한다. PoE 서버의 비공개 공식 복원이라고 부르지 않는다.

## 실제 전투

- 기본 미궁은 난이도1~100에 구역당 총50마리, 이후100단위로 증가해901~1000은200마리. 이는 초기 생성과 증원을 합한 총수이며 마지막 구역은 보스를 포함한다. 1000 이후에도200을 초과하지 않는다.
- 몬스터 HP/공격력은 Decimal로 성장하고 구역·종족·보스 여부가 반영된다. 물리 방어/원소·혼돈 저항, 명중, 용기·정신력의 상호 피해, 강인함의 CC 지속시간이 실제 타격에 적용된다. 1000 이후 공격 속도·관통도 높아진다. 별도 신규 보스 스킬/VFX를 생성한 것은 아니다.
- 일반 공격, 액티브·발동·군주얼 부여 스킬, 지속 피해에 같은 방어 경로를 적용한다. DoT는 이미 방어 계산한 피해를 다시 방어 계산하지 않도록 원시 피해를 저장한다.
- 캐릭터 기본 치명타를 빼던 차이 계산을 제거했다. 기본5% 및 실제 훈련·노드 보너스를 합산한다. 치명타 피해도 네이티브 기본값과 노드 추가분으로 계산한다. 현재 장비 패널의 기초 수치와 실제 전투 합산치는 구분한다.
- 원본 enum에 따라 강인함=11, 명중/집중력=12로 UI 라벨을 교정했다. 기존 저장 숫자는 바꾸지 않는다.

## 정산 안전성

엔진은 실제 양수 HP→0 전이에만 누적 XP/골드/처치/보스 처치 수를 올린다. 서비스는 요청 전후 누적 차이를 지급하고 플레이어 revision·일일 상한·보스 아이템 영수증을 같은 SQLite 트랜잭션으로 커밋한다. 같은 요청 sequence는 캐시된 결과만 반환한다. SQL/COMMIT 실패 시 런타임 세션도 버려 DB와 어긋난 처치가 나중에 살아나지 않게 한다.

보스가 요청 시작 시 없었다가 같은 요청의 연속 타격 중 생성·사망하는 경우도 누적 보스 처치 카운터로 감지한다. 미궁 첫 처치 영수증은 원본 캠페인과 다른 이름 공간을 사용한다. 두 미궁 런이 동시에 같은 난이도를 클리어해도 해금은 한 단계만 진행한다.

보유 골드는 실제 지급·차감된 지갑을 표시한다. 전투 결과의 산출 EXP/골드는 일일 한도 적용 전 값임을 명시하고, 조작 패널에 오늘 지급된 전투 보상을 별도로 표시한다. 방치 보상은 별도다. 날짜 상한은 UTC 기준이며 서버 시간이 역행해도 일일 예산을 다시 주지 않는다.

## 함께 보완한 운영 오류

2026-11-01 Render 종료 로그의 `database is locked`는 WAL 설정을 대기 설정보다 먼저 실행하던 초기화 순서 문제였다. 모든 SQLite 생성 경로에서 busy_timeout을 먼저 설정하고, WAL 변경은 잠금 오류에만 제한된 재시도를 한다. 별도 프로세스가 새 DB를 독점하는 실제 시험으로 확인한다. 기타 SQL 오류는 숨기지 않는다. 기존 파일 이전 영수증은 쓰기 트랜잭션 안에서 다시 확인해 웹·포커가 동시에 이전을 시작해도 중복 이전으로 종료하지 않는다. 6개 별도 프로세스의 동시 개방으로 보존을 검사한다.

GitHub 포커 CI는 하위 서버 패키지만 설치해 새 RPG 공통 코드의 루트 `break_infinity.js`를 찾지 못했다. 루트 및 서버 의존성을 모두 lockfile로 설치하도록 하고, 하이브리드/방치 회귀 검사도 추가했다. 기존 v4 액션의 런타임 폐기 안내는 이번 컴파일 실패와 별개 경고다.

영구 저장 및 유료 인프라 전환은 사용자가 보류했으므로 적용하지 않는다. 같은 파일의 트랜잭션 보존과 Render Free 인스턴스 교체 간 영구 보존은 다르다. 현재 무료 파일시스템의 유실 가능성은 그대로다.

## 검증 경계

일반 회귀 + 실제 SQLite 두 연결·별도 프로세스·저장 실패 주입·정확한 처치 전이로 검사한다. 별도 TLA+/Lean 증명은 수행하지 않았으며, 테스트가 모든 운영 환경과 모든 고난도 빌드의 밸런스를 보장하지 않는다. 장기 최고 레벨 시간 곡선은 초기60일 검증과 별도 조정 대상이다.
