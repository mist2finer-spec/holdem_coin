# RPG 몸체 충돌·회피·지면 보완

포커 규칙/배분은 변경하지 않는다. 이번 변경은 사냥 프로토타입의 클라이언트 전투와 렌더링에 한정한다.

## 이동과 타격

- 일반 좌우 이동, 자동 접근, 접근 Rush에 살아 있는 슬라임의 몸체를 장애물로 적용한다.
- 시작점~도착점 전체를 검사하는 swept interval을 사용하므로 빠른 Rush나 큰 프레임 간격에서도 통과하지 않는다. 동작 종료 시 목적지로 강제 순간이동하던 경로도 제거했다.
- 월드 단위의 플레이어 반경 16, 절반 크기 슬라임 반경 20으로 접촉선을 정한다. 무기/이펙트의 전체 스프라이트 폭은 몸체 충돌 폭으로 사용하지 않는다. 이 값은 웹 프로토타입 설계값이며 원본 바이너리의 collider 복원값은 아니다.
- 기존 타격 시점, 사거리, 방향, 대상 세대 ID 검사를 유지한다. 살아 있는 다른 슬라임이 앞을 가리면 뒤의 대상에게 관통 피해를 주지 않는다. 한 타격은 한 대상에 한 번만 적용한다.
- 죽은 몸체는 이동을 막지 않는다. 플레이어와 겹치는 위치에서 부활하려는 슬라임은 빈 공간이 생길 때까지 재생성을 미룬다.

## 회피

회피만 몸체 통과를 허용한다. 요청한 회피 경로가 접촉하는 살아 있는 몸체를 센다. 단순히 화면 전체나 전방 전체의 몬스터 수를 세지 않는다.

- 0~3마리: 이동 회피 가능. 목적지가 몸체 내부면 회피 거리 안의 빈 공간으로 착지를 줄인다.
- 4마리 이상: 이동 없이 avoid1을 재생하는 제자리 구르기. 기존 회피 시간/쿨다운은 소비한다.
- 안전한 착지점이 없으면 제자리 구르기. 월드 경계도 적용한다.
- 착지 순간에도 공간을 다시 확인한다. 원본 무적/피해 감소 공식은 이 변경에 추가하지 않았다.

## 렌더링 지면

- 기존 슬라임 배율 2.4에서 1.2로 변경: 가로·세로 각각 절반.
- 슬롯마다 다르던 지면 Y 오프셋을 제거한다.
- 플레이어는 Rleg/Lleg2 발/다리 attachment의 실제 posed 정점 중 최하단, 슬라임은 body attachment 최하단을 공통 floor Y에 맞춘다. Region과 Mesh attachment를 모두 처리한다.
- 무기/꼬리가 발보다 아래로 내려오는 프레임이 지면을 바꾸지 않게 플레이어는 다리 슬롯만 검사한다. 크기·좌우 반전·애니메이션 변형 뒤에 보정해 몸체의 바닥이 뜨거나 땅에 파묻히지 않게 한다.
- 캔버스의 data-ground-error, data-slime-scale로 실제 렌더 결과의 정렬 오차와 배율을 확인할 수 있다.

## 검증

`npm run test:rpg`: 25개 테스트 통과. 기존 20개 전투/뷰포트 테스트에 일반 이동 좌우 충돌, 고속 Rush 장애물, 3/4마리 회피, 밀집 착지, 사체 통과, 부활 겹침, 가려진 대상 타격을 추가했다. 실제 Spine 36개 애니메이션을 두 화면 배율/좌우 반전으로 재생하며 매 프레임 발/몸체 하단과 지면 오차가 0.002px 미만인지 확인한다. 대상 RPG TypeScript 검사와 프로덕션 빌드도 통과했다.
