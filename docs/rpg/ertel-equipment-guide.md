# 에르텔 장비 세공 · 업로드 12345 가이드 적용

- 피해 숫자는 렌더링용 라벨에서 반올림한다. 실제 HP·피해는 기존 Decimal 계산을 유지한다. 초거대 수는 소수점 없는 정수 계수와 지수로 표시한다.
- 메인 회랑 하단: 성장(훈련·특성·공용 트리), 소지품(장비·에르텔 세공), 주점(홀덤), 던전, 소환, 가방. 추가 던전은 준비 상태로 표시한다.
- 새 장비는 등급·종류별 기존 최대 홈 한도 안에서 0~한도 사이 홈 수를 균등 추첨한다. 최대 6홈. 기존 장비의 홈과 에르텔은 보존한다.
- 인접 홈 연결: 각각 독립 35%. 6홈이 모두 연결될 조건부 확률은 0.35^5 = 0.52521875%. 모든 홈이 찬 것과 모두 연결된 것은 별개이다.
- 홈 색상: 적·녹·청 각 32%, 백 4%. 백색은 모든 에르텔을 받는다. 에르텔 색상은 현재 태그로 분류하며 UI와 서버가 같은 함수를 사용한다.
- 첫 홈은 액티브, 이후 홈은 보조이다. 첫 홈과 연결된 보조만 전투 컴파일에 포함한다. 연결이 끊겨도 장착 복사본을 계속 예약한다. 다른 연결 그룹의 추가 액티브 시전은 이번 범위에 포함하지 않았다.
- 예전 색상·연결 필드가 없는 장비는 백색·전체 연결로 해석하여 기존 빌드를 보존한다.
- 세공 재료는 현재 영혼석: 색상 20 / 연결 50 / 홈 40. 원본 드롭·확률 복원이 아닌 무료 재화용 웹 테스트 정책이다.
- 홈 세공은 모든 장착 에르텔을 창고로 반환한다. 색상 세공은 맞지 않는 에르텔을 반환하고, 액티브가 제거되면 보조도 반환한다. 컬렉션 총수량은 줄이지 않으며 장착 예약만 해제한다.
- 기존 서버 시퀀스·SQLite 트랜잭션 안에서 세공한다. 재시도 시 중복 차감하지 않는다. 영구 저장 서비스는 추가하지 않는다.
