# 780 속성 트리·주얼 구현 기록 (2026-11-01)

이 문서는 이번 변경의 실제 동작과 제공된 세 PDF에서 조정한 부분을 기록한다. PoE 원본 게임의 완전한 재현이나 제공 문서의 메타 점유율 검증을 주장하지 않는다. 기준 소스는 `PoE_780노드_속성기반트리_설계.pdf` (DESIGN-006), `PoE_주얼시스템_전체설계.pdf` (FULL-007), `PoE_SSF_랭커빌드_카탈로그.pdf` (BUILDS-005) 전체다.

## 구현과 저장 호환성

- 정적 노드 **780**: Small 350, Notable 250, Keystone 25, Jewel Socket 25, Start 9, Hub 80, Travel 41. 동적 군주얼 노드는 이 780에 추가된다.
- 기존 **222개 ID 및 모든 250개 연결과 수치 효과**를 유지한다. 기존 v1→v2 마이그레이션과 6액티브×5보조 링크, 12~51 포인트 예산도 유지한다. 좌표와 시각적 분류는 변경된다.
- v2 저장에 선택 필드 `jewels`만 추가한다. 기존 저장에 이 필드를 강제로 추가하지 않는다. 군주얼의 할당 ID도 저장·재시작 때 서버가 같은 seed/instance에서 재생성하므로 유지된다.
- 홍 STR 0°, 백발 STR/DEX 45°, 후드 DEX 90°, 금빛 DEX/INT 135°, 안경 INT 180°, 청록 INT/STR 225°, 장발 INT/STR 270°, 정장 DEX/INT 315°, 오피스 중앙. 화면상 양의 각도는 반시계 방향이다. 시작 반경 400, 중앙 0.
- 새로운 속성 노드는 작은 원형 군집으로 배치한다. 기존 연결 비용을 보존하며, 내부 소켓은 같은 깊이의 중앙 경로에 연결해 소켓 진입 경로가 실제 반경 안에 들어오게 했다.
- 25 소켓은 내부 Timeless 8, 중간 Large 12, 외곽 일반/고유 5. 소켓 자체도 포인트를 소비한다. 캐릭터 간 이동도 포인트가 필요하다. 현재 플레이 가능 캐릭터는 기존과 같이 홍이며, 9개 시작점의 그래프/빌드 데이터는 모두 존재한다.

## 실제 주얼 동작

**일반 구조.** 아이템 인스턴스는 `instanceId / jewelId / seed / conqueror?`로 식별한다. Seed는1~10000 정수. 서버 보유 아이템에서 읽은 불변값만 장착할 수 있다. 장착은 `socketId / order`를 추가하고 마지막 장착 순서를 서버가 부여한다. 타입이 다른 소켓, 할당하지 않은 소켓, 중복 인스턴스/소켓/순서, 없는 부모 군주얼, 세 번째 Large, 이미 장착한 소켓 교체는 거부한다. 해제는 하위 할당 노드나 하위 주얼이 남아 있으면 거부한다. 전체 초기화/시작점 변경은 주얼을 보관함으로 되돌리고 노드 포인트를 초기화한다.

**Timeless.** 반경310 좌표 단위의 원을 사용한다. 고정 매핑과 seed 해시로 결과를 재현하고, 한 노드에 여러 반경이 겹치면 가장 나중에 장착한 주얼 한 개를 **원본 노드에** 적용한다. 이전 변환 위에 누적 변환하지 않는다. 시작점/소켓/Keystone/동적 군주얼 노드는 변환 대상에서 제외한다. 변환 효과는 실제 할당한 노드에 대해서만 합산한다. UI는 원본/변환 후 효과와 반경을 표시한다. 결과 그래프는 상태 서명별 최대24개 캐시, 패시브 합산은 그 그래프별 캐시를 사용한다.

| Timeless | 실제 적용 |
|---|---|
| Lethal Pride | 소형 힘+5; 주요 노드를 생명력/힘, 근접/방어도, 공격속도/흡수 중 시드 테마로 변경 |
| Brutal Restraint | 소형 민첩+5; 주요 노드를 회피/이속, 민첩/공속, 투사체/치명타로 변경. 노드별5% 해시 판정으로 이속+5%; 매 프레임 재추첨하지 않음 |
| Militant Faith | 소형 지능+5; 원소/주문/오라 주요 노드로 변경; 할당 노드당 헌신+5. 헌신1당 원소 피해+0.1%는 문서에 소비처가 없는 자원을 실제 효과로 연결한 자체 규칙 |
| Elegant Hubris | Eternal 주요 노드; 반경 내 할당 대상당 Triple Damage+5%, 총50% 상한. 소형 요구+50%를 정수 포인트 비용 `ceil(1.5)=2`로 구현. 장착 즉시 예산을 재검증 |
| Glorious Vanity/Doryani | INT/STR→DEX; ES%→회피%, ES/Life flat1→회피0.1%; Spell Damage→Attack Speed; Life%→회피%; Melee→Attack. 대상당 Life flat−1 |
| Glorious Vanity/Atziri·Xibaqua | STR/DEX→INT; 회피%→ES%; Attack/Melee/Physical→Spell; Attack Speed→Cast Speed; Life%/flat→ES%/flat. 대상당 Life flat−1 |

Conqueror3종은 각 Timeless의 시드 테마 선택에 참여한다. Vaal은 위의 변환 규칙이 우선한다. Atziri와 Xibaqua는 현재 엔진에서 동일한 수치 변환을 사용하며 별도 문서 효과가 없는 추가 차이를 꾸며내지 않는다.

**Cluster.** Large는9테마,10노드(주요2/중형소켓2/소형6); 주요 노드2개를 해당 테마의3개 후보에서 seed로 고른다. Medium은8테마,5노드(주요1/소형소켓1/소형3). Small은9테마,3노드(주요1/소형2)이며 자식 소켓이 없다. 모든 생성 노드도 일반 포인트/연결성 검증을 받는다. Small의 명시된 주 효과는 주요 노드에 집중된다. Medium의 보조 성장 노드는 모든 피해+2%이다. 함정/소환수/토템 테마는 작동하지 않는 상품으로 노출하지 않고 아래 대체 항목을 사용한다.

**추가 스킬.** 할당한 Large 주요 노드가 실제 별도 스킬을 최대4개까지 부여한다. 기존6액티브/보조 링크를 차지하지 않고 보조 젬도 붙지 않는다. 현재 엔진의 이미 구현된 스킬로 연결하며, 가까운 적이 있을 때 독립적으로 자동 시전한다. 기본8초×재사용 배율(최소2초), 정상 마나/혈마법 비용, 일시정지/기존 동작 완료 조건을 따른다. 추가 시전의 타격/반복/DoT는 다른 발동 스킬의 원인이 되지 않는다. 소환수/토템의 가짜 시전은 추가하지 않았다.

**고유/일반.** Crimson/Silver/Cobalt는 속성+10 및 테마 수치+시드 보조 모디1개(생명력4%/원소 저항4%/마나6%). Prismatic은3속성+10과 모든 피해+10%. Split Personality는 현재 할당 그래프의 시작점→소켓 **최단 경로** 길이에 따라 생명력5%×clamp(거리/4,1,5)를 제공한다. Watcher's Eye는 실제 시전된 Hatred 오라 지속 중 냉기 피해×1.2, Vitality 오라 지속 중 초당 생명력1% 재생(재생 불가 상태 제외)을 제공한다. 지원되지 않는 Anger/Discipline 조건은 사용하지 않는다. 현 엔진은 동시에 한 오라 효과를 유지한다. Forbidden Flame/Flesh는 동일 seed 한 쌍일 때 생명력+12%/막기+8%; 종류별1개 제한이며 Ascendancy 복제는 없다. 일반 고유10종은 실제 수치 효과만 제공한다. Blue Pearl은 최대 혼돈 저항 증가 대신 현 상한 내 혼돈 저항+15%다.

## 전투 수치 및 Keystone 조정

주요 대상은 현재 서버 권위 `RogueEngine`이다. 기존 캠페인도 공유 패시브/스킬 컴파일러와 쿨타임 표시는 사용하지만, Rogue 전용 ES/MoM/회피/독립 군주얼 시전까지 같은 수준으로 확장된 것은 아니다.

- STR1→flat Life0.5+근접 피해0.2%; DEX1→회피 보정0.2%+공속0.1%; INT1→flat Mana0.5+ES0.2%. 이 환산은 원문이 정하지 않은 부분의 자체 규칙이다.
- Life/ES/Mana flat과%를 분리한다. Life=(10000+flat)×(1+Life%), ES=10000×ES%+flat, Mana=(100+flat)×(1+Mana%). Life/ES와 피해는 기존 BigInfinity scale을 유지한다.
- 방어도 감소=min(75%, armour/(1+armour)), 회피율 보정=evasion/(1+evasion)×40%; 별도 Dodge와 합해75% 상한. Spell Dodge는 주문(비물리) 수신에 적용. 원소/혼돈 저항 상한75%, 막기75%, 억제80%. 원본 PoE의 방어도/정확도/명중 등급 공식은 아니다.
- 공격/시전 속도는 해당 스킬의 재사용 간격에 반영하고, 공격 속도는 기본 공격 동작/적중 타이밍에도 반영한다. 시전 애니메이션 속도는 별도로 바꾸지 않는다.
- MoM은 보호막이 먼저 소모된 뒤 생명력에 도달할 피해 중30%(다른 증가와 합산 최대50%)를 마나로 지불한다. Big 피해를 scale로 나눠 자원 비용을 계산하고, 실제 보유 마나만큼만 흡수한다.
- EB는 ES 방어층을 제거하고 scale 전 ES 수치를 마나 최대치에 더한다. CI는최대HP1/혼돈면역을 실제 적용한다. Vaal Pact는 엔진의 기존 즉시흡수+재생불가를 사용한다.
- Blood Magic(가이드 명칭 Zealous Oath)은 마나 대신 생명력으로 스킬 비용을 지불하며 비용으로 자살할 수 없다. 저생명력≤50% Pain Attunement 주문 ×1.3, 거리300에서 Far Shot 최대×1.5, Culling Strike≤20% 적 즉시 마무리, Triple Damage 확률은 실제 타격에 적용한다. Culling은 시전/DoT 스냅샷을 보존한다.
- Avatar of Fire는 스킬 피해 속성/태그를 화염으로 변환한다. 물리 전용 보조와 충돌하는 빌드는 검증에서 거부한다. 일반 공격은 도끼 물리 공격을 유지한다.
- Resolute Technique: 이 엔진은 원래 직접 공격에 명중 판정 실패가 없으므로 치명타 불가+물리 피해30%를 사용한다. Elemental Overload는 기존 규칙인 원소×1.4/치명타불가를 따른다.
- Overleech→Slayer Recovery(즉시 흡수8%+재생2%), Constitution of Faith→원소30%/치명타10%, Shaper of Storm→냉기35%/원소15%, Elemental Equilibrium→원소25%/모든 피해×0.9, Bastion of Hope→막기30%/피해×0.9, Ancestral Bond→Ancestral Guard(보호막40%/피해×0.85). 실제 적 저항 변화/최근 막기/지속흡수/토템을 흉내 낸 무효 플래그는 없다.
- Legacy30의 수치와 제한은 기존 저장을 위해 그대로 남는다. 신규25와 둘 다 투자하면 중첩될 수 있고 공통 방어 상한을 적용한다.

60핵심 Notable은 속성 테마별로 반영하되, 문서에 효과가 없는 나머지250개 전체에 새로운 고유 효과를 꾸미지 않고 기존/신규 테마를 반복한다. Notable의 개별 조정: Endurance Charge당 Juggernaut→고정 방어도24%; Melee Range+4→면적16%; 이동 중/최대HP 피해 조건→항상 적용되는 공격/모든 피해; 투사체 속도→공격 속도; 활 피해→투사체 피해; 냉기 단독 저항→공통 원소 저항; 공격 한정 Crit→공통 Crit; 마나흡수→마나재생; Lord of the Dead/Witch's Lament/Totemic Bond→주문/ES/시전 속도; Trapper/Prolonged Pain→투사체 또는 DoT/쿨타임. Medium Curse는DoT/혼돈으로, Minion은Arcane Ward로, Totem은Battle Bond로 대체한다. Large Crit80/60%는25/20% 절대 확률로 제한하고, 투사체속도/표식/반복/속성%도 카탈로그에 있는 실제 속도/치명타/시전속도/flat속성으로 조정했다.

## SSF 카탈로그의 반영 범위

카탈로그는 생명력·저항·재생·ES·속성별 피해·6링크의 빌드 방향을 제공한다. 신규35/30 스킬 목록을 8개의 실제 PoE 빌드로 완성한 변경은 아니다.

| 빌드 | 지원되는 현재 구성 | 이번에 추가하지 않은 메커니즘 |

## 검증과 경계

`npm run check:rpg`, `npm run test:rpg:build`를 실행한다. 신규 core 테스트는 정확한 분포/기존222/시작점, Vaal3변종과Timeless5종, 겹침/해제, 798중첩 그래프/연결/환불, 타입/소유인스턴스/시드/순서/2Large한도 위조, Split/Forbidden, 실제 슬롯외 시전/발동 차단, BigInfinity MoM/EB/혈마법/Culling, 쿨타임 원본시간/일시정지를 검증한다. 기존1000개 prefix 그래프와 1050개 액티브/보조 조합 검증을 유지한다. 바뀐 기존 테스트의 고정 수량 기대값만222→780으로 갱신했다.

`AGENTS.md`에 따라 일반 단위/통합/회귀 테스트를 우선했다. 핵심 그래프/주얼 판정은 순수 결정 함수이고, 새 비동기 프로토콜 없이 기존 서버 순서/SQLite 트랜잭션을 사용하므로 이 범위는 실제 구현에 대한 위조/재시도/동시접속 테스트로 직접 검사하는 편이 유효하다. 별도의 TLA+/Lean/Kani 모델은 만들거나 검증했다고 주장하지 않는다. 통과 결과는 검사한 범위의 증거이며 모든 오류 부재나 모바일60fps 보장을 뜻하지 않는다.

## UI·상점·저장 운영 경계

모바일 장착은 가이드의 드래그앤드롭 대신 **소켓 선택→보관함 드롭다운→장착/해제 버튼**을 사용한다. 변환된 노드 색상과 원본/변환 후 설명, 군주얼의 실제 자식 노드는 표시한다. 쿨타임은 서버가 시전 시 저장한 전체시간(`cooldownTotals`)과 남은시간을 사용해 회색 가림막·원형 진행·숫자를 그린다. 중간에 빌드가 바뀌어도 이미 시작한 쿨타임의 분모가 달라지지 않는다. 재시전 대기는 기존 동작대로 가능하고 일시정지는 실제 타이머를 멈춘다. 복원 소스의 `_gaugeFill`/`_gaugeText`/`RefreshGauge` 흔적을 참고한 UI이며, 제거된 원본 함수 본문과 동일한 애니메이션이라고 주장하지 않는다.

상점은 서버 카탈로그 가격을 사용하며, 클라이언트 금액/시드/주얼 스탯을 신뢰하지 않는다. 서버가 구매자의 연결된 게스트 인벤토리에 주얼 인스턴스를 발급한다. 동일 영수증 재전송은 재차 과금/지급하지 않고 SQL 지급 실패 시 현재 지갑 차감도 남기지 않는다. 기존 HOLDEM 지갑은 메모리 기반 데모 잔액이므로 계정 자산 전체의 영구 원장으로 바꾼 변경은 아니다. 주얼/빌드는 제공된 SQLite 저장소의 생존 기간 동안 저장된다. 현 배포의 ephemeral 디스크가 새 배포/재시작으로 사라질 수 있으므로 **배포를 넘어 영구 보존된다는 보장**은 하지 않는다.

실제 속성 라벨 분포는 STR109 / DEX77 / INT78 / STR_DEX76 / DEX_INT149 / INT_STR151 / ALL140이다. 가이드 영역별 155/70 배분 자체의 합산은 정확하지만, 기존222 유지·중복 하이브리드 캐릭터 배치·정확한 종류별 수를 우선하여 이 배분은 조정했다. 기본 카탈로그 상품은49종이다. 현재 검증은 단위/통합/서버 시뮬레이션에 대한 것이고 모든 모바일 기기의 프레임률이나 콘텐츠 밸런스를 실측 확정한 것은 아니다.
