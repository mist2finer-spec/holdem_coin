# 촛불 미궁 — 10개 방 2D 로그라이크 테스트

## 범위

기존 미궁 단계/성장 전투와 분리된 서버 기반 테스트 런이다. 시작의 숲과 Map002_001 조립 복원 화면은 선택지로 보존한다. 기본 선택은 `10개 방 · 로그라이크 테스트`다. 홍만 선택 가능하며 다른 캐릭터의 에셋은 삭제하지 않는다.

이 모드의 지도와 전투 수치는 **신규 웹 테스트 어댑터**다. 바르디안 원본의 로그라이크 생성 로직을 복원했다는 의미가 아니다. 원본에서 복원한 돌바닥/벽/불꽃 텍스처와 캐릭터·몬스터 Spine 리그를 재사용한다. 원작의 카메라와 모든 피해/성장식을 동일하게 재현했다고 주장하지 않는다.

## 비율

지도와 배우에 같은 월드→화면 배율을 적용한다. 타일 48, 홍 몸통 기준 높이 88, 벽 높이 52, 소형 몬스터 높이 40, 보스 높이 94 월드 단위. 홍의 기준 높이에는 도끼 끝이나 장식 머리카락을 포함하지 않는다. 통로 폭은 3타일(144)이며 일반 방 너비는 9~12타일로 640 월드 단위의 가시 폭 안에 대략 들어온다. 세로 지면만 0.72 원근 비율로 투영하고 배우는 원본 종횡비를 유지한다.

모바일 세로 프레임과 기존 전투창/조작창의 44:56 배분을 유지한다. PC는 동일 스마트폰 프레임 안에서 출력한다. 기존의 긴 3D 회랑 베이크를 확대 배경으로 쓰지 않고, 원본 `ground_tile01`과 `WallType1_01` 텍스처를 방과 통로에 배치한다. 촛불은 원본 4×4 불꽃 시퀀스다.

## 생성과 탐색

- `rot-js@2.2.1`, BSD-3-Clause. [원본 저장소](https://github.com/ondras/rot.js), [Uniform 소스](https://github.com/ondras/rot.js/blob/master/src/map/uniform.ts).
- Uniform이 겹치지 않는 방 후보를 생성하고 그중 10개를 보존한다. 최소 신장 트리로 연결한 뒤 2개 순환 연결을 추가한다.
- 생성은 최대 3회, 각 70ms로 제한한다. 실패 시 시드 기반 10개 방 배치를 사용하고 같은 통로 연결/검증 절차를 따른다.
- 전역 ROT RNG 상태와 seed를 동기 생성 후 복원한다. 정상 경로의 동일 seed는 같은 지도를 만든다. 매우 느린 호스트의 시간 제한 fallback은 다른 생성 경로를 선택할 수 있다.
- 방/통로를 연속 이동하며 도달한 방과 정리한 방을 구분한다. 출구는 출발점에서 타일 경로상 가장 먼 방 중 하나에 배치한다.
- PreciseShadowcasting 시야, 탐색 흔적, 소형 지도가 있다. 미니맵은 테스트 탐색 편의를 위해 미방문 방/연결도 어둡게 보여준다.

## 몬스터와 전투

총 10개 방 중 입구는 안전 구역이다. 나머지 방에 3~5마리씩 배치한다. 불/물/숲 슬라임, 오염체, 단검/검/주술 고블린, 거미 등 원본 8종과 출구 방의 슬라임 군주 보스를 사용한다. 모두 실제 JSON/atlas를 확인한 리그다. 사망 몬스터는 해당 런에서 재생성하지 않는다. 모든 방을 탐색·정리하고 출구에 도착하면 완료한다.

상하좌우/대각 이동은 벡터 정규화로 같은 속도를 유지한다. 벽 충돌은 원형 몸체와 소단계 sweep을 사용한다. 몬스터는 같은 방의 탐색/거리 조건으로 활성화되고, 벽에 막히면 ROT Dijkstra 경로를 사용한다. 공격 예고 시점의 위치와 타격 시점 거리/시선을 다시 검사한다. 벽 너머 공격은 막는다. 원본의 다른 애니메이션/지연값을 참고하되, HP/피해/보상은 이 테스트의 고정 수치다.

AUTO는 근처 몬스터 기본 공격만 수행하며 다음 방으로 자동 이동하지 않는다. 일반 공격은 5타 순환, 수동 스킬 3개(원형 공격·전방 공격·회복), 회피와 점프가 있다. 점프/회피는 벽을 통과하지 않으며 안전 착지를 검사한다. 점프는 별도 무적 효과를 주지 않는다. 현재 아트는 측면 리그를 2.5D 지면 위에서 움직이는 방식이며, 상하 이동 전용 전후면 공격 리그는 후속 작업이다.

## 저장·검증 범위

서버 세션이 seed·시간·좌표·피해·처치를 소유한다. 요청은 ID와 증가하는 sequence로 순서를 검증하고 재시도 시 같은 결과를 반환한다. 요청 간 시간은 최대 0.25초로 제한하며 오프라인 전투는 하지 않는다. 세션 교체 시 이전 ID를 거부한다. 캐릭터 제한은 서버에서도 검사한다.

**기존 계정의 골드·레벨·장비를 변경하지 않는다.** 화면의 골드는 현재 테스트 런의 기록이며, 새 미궁 생성/재입장 시 초기화된다. 던전 레이아웃·런 세이브, 영구 보상, 아이템 드롭, 방별 이벤트/문 잠금, 높이차/낙하, 원본 특수 공격 전체 이식은 아직 미구현이다.

`npm run test:rpg:rogue`는 100개 seed 연결성·10개 방·경계, RNG 복원, 벽 관통 방지, 2D 속도, 에셋 참조, 처치 중복 보상, 비재생성, 세션 격리·중복 요청·시간 상한을 검사한다. 기존 테스트로 해당 불변 조건을 직접 확인하므로 추가 형식 검증 모델은 만들지 않았다.
