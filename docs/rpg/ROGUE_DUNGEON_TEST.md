# 촛불 회랑 — 바르디안풍 구역 진행 프로토타입

## 현재 규칙 (2026-10-30)

기존 자유 탐색형 방 그래프를 **좌우로 연결된 전투 구역 10개**로 바꿨다. 원작의 방 배치 데이터를 그대로 복원한 것이 아닌 신규 웹 어댑터이며, 바르디안에서 추출한 돌바닥·벽·촛불 텍스처와 홍/몬스터 Spine 리그를 재사용한다. 이전 구현은 Git 커밋 `a5a4ec0`에 보존되어 있다.

1. 구역 진입: 해당 구역의 몬스터 3~5마리를 한 번만 생성한다. 1구역도 전투 구역이며, 아직 진입하지 않은 구역에는 몬스터가 없다.
2. 전투: 현재 구역 안에서 상하좌우로 움직인다. 모든 적을 처치하기 전에는 구역 밖으로 나가지 못한다.
3. 출구 개방: 적 전멸 후 오른쪽 원형 발판으로 이동한다. 표시된 점프 또는 슬라이딩 버튼을 누르면 다음 구역으로 통과한다.
4. 점프 출구는 바닥 틈, 슬라이딩 출구는 낮은 석문이다. 1→2는 점프, 2→3은 슬라이딩으로 번갈아 배치한다.
5. 착지 완료 후에만 다음 구역 번호를 확정하고 다음 몬스터를 생성한다. 이미 정리한 구역으로 되돌아가거나 무한 리젠하지 않는다.
6. 10구역에 슬라임 군주가 등장한다. 모두 처치한 뒤 오른쪽 최종 출구에 닿으면 탐험이 완료된다.

AUTO는 같은 규칙으로 1~10구역을 차례대로 사냥하고, 출구 접근 및 점프/슬라이딩도 수행한다. 수동 이동은 AUTO보다 우선한다. AUTO를 다시 켜면 현재 진행 상태에서 이어간다.

## 코드와 상태 대응

| 코드 | 책임 |
|---|---|
| `rogue/map.ts` | seed 기반 구역 폭/깊이, 일렬 연결, 9개 `RogueGate` 생성 |
| `rogue/engine.ts` | 전투·생성·개방·통과·착지 및 AUTO, 피해/처치/보상 권한 |
| `rogue/renderer.ts` | 지형/틈/석문, 원본 Spine, 피해 숫자, 통과 안내 |
| `rogue/RoguePrototype.tsx` | 입력, 서버 응답 표시, 스킬·회피·점프·슬라이딩 버튼 |
| `rpg-rogue-service.ts` | 기존 세션 ID/sequence/재시도 중복 방지 |

`phase`는 `combat → exit-ready → traversing → 다음 combat`이다. 마지막은 출구 도착 시 `complete`가 된다. 구역 번호는 좌표만으로 바뀌지 않고, 적 전멸 및 요구 액션을 검증한 통과 동작의 착지로만 증가한다. 일반 이동·회피·잘못된 액션은 경계를 넘지 못한다. `spawned`와 `transitions`가 생성/통과 중복을 막고, 기존 세션 계약이 재전송을 같은 응답으로 처리한다.

구역은 9~11타일 폭, 6~8타일 깊이의 벨트 전투 공간이다. 다음 구역 연결은 144 월드 단위이며 시작점 40 단위 안에서 요구 액션을 누르면 출구 방향으로 정렬해 통과한다. 일반 전투 점프/슬라이딩과 통과 동작은 같은 재사용 대기시간을 공유한다. 통과하지 않는 일반 회피는 벽·안전 착지·최대 3마리 통과 제약을 유지한다. 서버는 입력만 받으며 클라이언트가 구역 번호나 통과 성공을 지정할 수 없다.

## 향후 공격 높이 판정 계획 — 이번 패치에 적 패턴은 추가하지 않음

맵 통과용 `RogueGate.kind`와 적 공격 판정은 별도 계층으로 유지한다. 통과 성공을 피격 무적 판정으로 재사용하지 않는다.

| 적 공격 유형 | 향후 회피 규칙 |
|---|---|
| 장판 | 표시된 지면 범위 바깥으로 이동하거나 정해진 회피 창 사용 |
| 상단 타격 | 슬라이딩의 유효 낮은 자세 구간에서 회피 |
| 하단 장풍 | 점프의 실제 높이가 장풍 판정보다 높을 때 회피 |

후속 구현에는 공격별 밴드·지면 범위·예고/타격 시간과 캐릭터의 높이/자세를 함께 검사하는 서버 판정이 필요하다. 현재 기존 몬스터 근접 패턴/회피 규칙은 유지하며, 점프가 모든 공격을 피하거나 슬라이딩이 새 상단 공격에 대응한다고 주장하지 않는다.

## 저장·검증과 제한

서버가 seed·시간·좌표·피해·처치·구역 전환을 소유한다. 요청 간 누적 시간은 최대 0.25초로 제한하고 새 세션은 이전 ID를 거부한다. 홍만 서버/클라이언트에서 선택 가능하다.

**기존 계정의 골드·레벨·장비를 변경하지 않는다.** 골드는 테스트 런의 기록이다. 재입장 시 초기화되며 영구 보상·아이템 드롭·오프라인 전투·중간 저장은 미구현이다. 무기/성장/가방/의뢰 창은 테스트 정보 패널이다. 기존 시작의 숲 및 원본 Map002_001 복원 전투는 별도 선택지로 유지한다.

`npm run test:rpg:rogue`: 100개 seed 연결성, 30개 seed AUTO 완주 및 통과 순서, 수동 완주, 잠긴 출구/잘못된 동작 우회 금지, 쿨다운, 안전 착지, 생성·보상 중복, 통과 중 중복 입력/서버 재전송, 기존 스킬 예약을 검사한다. 기존 RPG 회귀/타입/운영 빌드도 확인한다.

형식 검증은 추가하지 않는다. 동기 전환과 기존 ID/sequence 계약을 재사용하며 핵심 불변 조건을 직접 테스트한다. 도구를 실행하지 않은 것을 형식 검증 성공으로 보고하지 않는다.
