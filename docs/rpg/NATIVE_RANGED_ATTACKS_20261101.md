# 원거리 몬스터·보스 공격 복원 (2026-11-01)

## 적용 범위
현재 기본 `/hunt`의 Rogue 미궁에 적용한다. 기존 스테이지형 HuntEngine의 별도 전투 경로는 이번 변경 대상이 아니다. 기존에는 기본 미궁의 원거리 몬스터도 같은 근접 판정을 사용했다. 이제 서버의 EnemyAttackSystem이 시전, 지연, 투사체 이동, 도착/해제 판정, 반복 간격과 단일 타겟 중복 방지를 처리한다. 화면은 서버가 보내는 같은 위험 범위로 예고 표시를 그린다.

## 원본에서 확인한 데이터
기준은 복원된 `labyrinth-runtime.json`과 combat-chain 추출물이다. 추가 메타데이터는 `scripts/rpg/recover_enemy_attacks.py`로 재생성한다. 원본 추출물의 누락 필드는 null로 남기며 0으로 단정하지 않는다.

**메이지의 세 번째 공격:** 원본 설정은 고정 modulo-3가 아니다. 느린 AI의 3~4초 대기와 6초 특수 쿨타임이 합쳐져 기본 2회 뒤 특수가 나오는 경우가 많다. 고정 시드 회귀 검사에서도 이 순서를 확인했다. 타겟 거리/경과 시간에 따라 달라질 수 있다.

**독구름:** 현재 복원된 2161 효과는 120% 직접 피해이며 별도 독 지속 피해 디버프가 확인되지 않았다. 이름만 보고 임의의 DoT를 추가하지 않았다.

`enemy-attack-coverage.json`은 요청된 계열 및 다중 스킬 몬스터/보스 34종, 스킬 97개의 명령·미확인 항목을 기록한다. 보조 메타데이터는 전체 추출 대상 142개 액션을 포함한다. 이 숫자는 모든 공격의 완전한 원본 재현을 뜻하지 않는다.

## 이미지와 예고 표시
`public/rpg/vfx/enemy/manifest.json`에 9개 이펙트의 기존 프리뷰 GIF 이름과 SHA256을 기록했다. 32프레임 WebP 시트로 패킹해 전투에 연결했다. 갤러리는 `/rpg/vfx/enemy/index.html`이다.

- 초음파, 암흑 탄환, 낙하 기둥, 독구름, 불/물/땅 원소구, 낙하 범위, 폭발을 사용한다.
- 이 프리뷰는 원본 Unity 파티클을 근사 베이크한 기존 자료다. GUID→텍스처 전체 참조가 검증된 것은 아니며, 현재 매칭은 명시적으로 테마 기준이다.
- 원본 WarningMark의 Mesh/Renderer 및 텍스처 참조는 있으나 실제 WarningMarkBox 텍스처는 현재 자료에 없다. 노란 범위 표시를 코드로 재구성했다. 원본 PNG를 추출했다고 주장하지 않는다.

## 웹 전투에 맞춘 처리
원본 3D 좌표/충돌을 현재 X축 전투에 투영했다. 낙하의 세로 이동 0.35초, 산포 한도, 경고 타원, 저탄/상단/장판 분류는 웹용 어댑터다. 점프는 저탄, 슬라이드는 상단 초음파, 회피는 전체 판정을 피한다. 원본과 동일한 회피 높이 판정으로 검증된 것은 아니다.

적 시전 중 공격 애니메이션을 재생하고 사망/구역 이탈 시 남은 공격을 제거한다. 활성 위험 128개, 명령당 발사 64개, 임팩트 표시 96개로 제한한다. 자동 사냥은 이미 보이는 위험에만 반응하며 진행 중인 자기 공격을 회피 판단으로 계속 취소하지 않는다.

피해 계수는 원본 명령의 퍼센트를 사용하되 기본 미궁의 기존 난이도용 기본 공격력·방어·성장·피해 무적 시간에 연결했다. 현재 보스 기본값 90, 일반 45이며 원본 몬스터 최종 공격력 공식과의 1:1 일치를 뜻하지 않는다. 원소/카오스 분류 또한 현재 웹 빌드 시스템용 매핑이다.

## 남은 복원 경계
- 2305 박쥐 기본 액션의 효과 필터/심볼릭 인자가 미해결이라 피해를 임의 생성하지 않는다. 해당 박쥐의 확인된 2306 초음파는 동작한다.
- 일부 보스의 자기 회복·소환·돌진·자기 버프 전체를 이번 원거리 컨트롤러가 재현하지는 않는다. 조건이 미해결인 피해 명령은 실행하지 않는다.
- 원본 StartOrigin/TargetOrigin 전체 3D 의미, 모든 네이티브 셰이더, 장판 원본 텍스처는 추가 검증이 필요하다.
- 무작위 7개 보스 중 하나가 나오며, 모든 원본 보스를 미궁에 출현시키는 패치는 아니다. 공격 사전의 복원 범위와 실제 출현 목록은 구분한다.

## 검증
기존 실제 엔진 테스트를 우선한다. 시간/횟수 쿨타임, 예고 중 무피해, 이동 회피, 초음파 슬라이드, 저탄 점프, 추적 구름 단일 타격, 시전자 사망, 일시정지, 위험 개수 제한을 직접 검사한다. 자동 사냥 30개 시드의 구역 이동·최종 보스 클리어 회귀도 검사한다.

형식 검증은 이번에 실행하지 않았다. 별도의 동시성 프로토콜이나 저장 계약을 바꾸지 않았고, 단일 서버 틱의 실제 코드와 시드 시뮬레이션으로 관련 상태 전이를 직접 재현할 수 있어 추가 모델의 실익이 낮다고 판단했다. 이는 전체 프로그램 안전성 증명이 아니다.

검사 결과: `check:rpg`, 운영 `build` 통과. RPG 회귀 135건, 빌드 시스템 36건, 미궁 54건 통과. 이후 추가한 횟수 반올림 및 구역 이탈 테스트를 포함한 원거리 집중 테스트 9건도 통과(기존 7건과 2건 추가). 즉 고유 RPG 테스트 227건이 통과했다. 포커 코드는 수정하지 않았으며 이번에 포커 테스트를 재실행하지 않았다. 9개 WebP 시트는 모두 1024×512이고 유효한 이미지 영역이 있음을 확인했다.

시트 시각 QA에서 일부 기존 프리뷰의 불투명 배경과 DarkShot01/03의 깨진 셰이더 베이크를 발견했다. 암흑탄은 사용 가능한 DarkShot02 테마 프리뷰로 교체했고, 9개 시트 모두 모서리 배경색으로 근사 알파를 복구해 어두운 사각형이 전투 화면을 덮지 않게 했다. 이는 원본 알파 복원이 아니라 프리뷰 배경 제거다. 9개 시트의 투명 모서리 및 알파 범위 0~255를 검사했다.
