# 홍 던전 점프 테스트

- 배경: Map002_001 원본 조립 맵. 선택 기본값을 촛불 회랑으로 변경.
- 현재 서버에서 홍만 입장 가능. 다른 8개 캐릭터는 데이터·이미지를 보존하되 회색/빨간 선택 불가 문구와 disabled 처리.
- W / 위쪽 화살표 / 점프 버튼. 좌우 이동을 유지하면서 누르면 방향 점프, 정지 상태에서는 제자리 점프. 점프 입력은 AUTO를 끔. 공격 중 입력은 최대 1.5초 예약.
- 서버에서 0.86초 체공, 높이 140월드단위, 최대 210월드단위 이동, 1.05초 재사용. 원본 jump1~jump5 포즈를 체공 단계에 대응. 이 값들은 웹 테스트 어댑터이며 원본 점프 물리 수치로 확정한 것이 아님.
- 한 번에 최대 작은 몬스터 3마리 통과, 네 번째면 제자리 점프. 착지 시 생존 몬스터와 겹침 재검사. 점프 중 공격·회피·무기 교체 제한. 무적 효과는 없음.
- 바닥 검사: world X=-4 선의 Y=10 수평 삼각형 구간을 합치면 Z=-70.000002~14가 연속됨. 그림의 빈 공간만으로 낙하 구멍을 추가하지 않음. 원본 collider/오브젝트 동작 검증 전 플랫폼 점프·낙하·높이차는 미연결.
- 일반 테스트로 시간·입력·중복 요청·착지 불변 조건을 검사. 기존 명령 순서/중복 방지 프로토콜을 바꾸지 않아 별도 형식 검증은 생략.
