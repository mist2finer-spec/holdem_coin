# Cat 2연타 v6

v11 내려베기 → 도끼를 들어 연결 → v5 횡베기 → 기본 대기. 첫 공격 뒤에는 대기 자세를 넣지 않았습니다.

게임에서는 `hero040_attack_combo`를 한 번 재생합니다. 총 길이는 2.29초입니다. 이벤트 `hero040_combo_hit`의 int 값이 1이면 0.500초 첫 타격, 2이면 1.206667초 두 번째 타격입니다. 클립 종료 후 `stay1`으로 이어갈 수 있습니다. 첫 타격 시점은 v11의 타격 포즈를 기준으로 지정했습니다.

`preview-v6.html`에서 두 타격 시점 버튼과 슬라이더를 사용할 수 있습니다. 2,291개 포즈 검사, 두 타격 이벤트 순서, 최종 대기 위치, 브라우저 139프레임 렌더를 확인했습니다. 연결 도중 방향을 한 프레임에서 전환합니다. Unity에서의 전환과 실제 전투 판정은 미검증입니다.
