# Pink Glass 쿼터뷰 달리기 v3 — 힙과 척추의 전방 기울기

힙 관절을 살짝 앞으로 기울이고, 그 위의 척추와 가슴이 진행 방향으로 따라 나오도록 v2의 직접 작성 키프레임을 수정했다. 리뷰는 **쿼터뷰가 기본**이며 v2와 v3를 같은 걸음 위치에서 비교한다.

**Blender 제작·접지·루프·FBX 재입력 PASS. 사용자 미술 승인 대기. Unity 연결과 게임 검수는 미실행(UNAVAILABLE).**

## 리뷰

- `review.html`: 쿼터뷰 기본, 측면 선택, 일시정지·프레임 이동·0.5×·게임 속도 예시.
- `preview_quarter.gif`, `preview_side.gif`: v3 단독 반복.
- `compare_v2_v3_quarter.png`, `compare_v2_v3_side.png`: 같은 4개 포즈의 전후 비교.
- `poses_quarter.png`, `poses_side.png`: 8개 주요 포즈.

쿼터 카메라는 높이 55°·방위 55° 정사영이다. HTML은 각 시점 56프레임을 내장한다. GIF는 28장·930ms로, 정확한 0.933333초 박자는 HTML 또는 blend에서 확인한다.

## 수정한 자세

| 항목 | v2 | v3 |

| 힙의 전방 기울기 | 0° | **8°** |

| 목 / 머리의 전방 기울기 | 5° / 3° | 9° / 5° |
| 가슴 관절 위치 | 기준 | **약 3.37cm 앞으로** |

각도는 각 뼈의 모델 기준 절대 전방 기울기다. 부모마다 이 값을 더하는 방식이 아니다. 힙의 기울기와 척추 회전을 이어 상체가 앞으로 나오게 했으며, 뼈를 늘리거나 기준 자세를 바꾸지 않았다. 몸통의 좌우 비틀림은 없다.

힙 회전 후 양쪽 다리 포즈를 다시 풀어 v2의 발 경로를 유지했다. 팔 흔들기·손가락·걸음 박자·주기 거리는 v2와 같다. 왼팔은 오른팔 진폭의 85%로 자유롭게 흔든다.

## Claude 연결 계약

| 항목 | 값 |
| --- | --- |
| 액션 | `AN_PG_QuarterRun_v3` |
| 적용 대상 | 쿼터뷰 달리기만. 사이드뷰는 기존 클립 유지 |
| 리그 | `Armature`, `mixamorig:` 65뼈. 현재 캐릭터 이름·계층·기준 자세 동일 |
| 타임라인 | 60fps, 프레임 1~57. 57은 1의 중복 경계 |
| 두 걸음 주기 | **56프레임 간격 = 0.933333333초** |
| 주기 거리 | **2.24m × 모델 월드 배율 S** |
| native 재생 1× 속도 | **2.4m/s** |
| 루트 | 제자리. Hips 수평 이동·yaw·roll 없음, 수직 바운스와 **일정한 전방 pitch 8°** 포함 |
| 접지 | 왼발 phase 0~0.24, 오른발 0.50~0.74 |
| 축 / 단위 | Blender −Y 진행 → FBX/Unity +Z. native 1unit=1m, Armature scale 1 |
| FBX 내용 | 리그 1개·65뼈·클립 1개. 메시·재질·무기 없음 |

```text
재생 배율 = 실제 월드 이동 속도(m/s) / (2.4 × 모델 월드 배율 S)
S=1, 3.9m/s → 1.625×
```

**v2와 달리 Hips에는 일정한 전방 회전이 있다.** 이 pitch는 자세의 일부로 보존하고 캐릭터 루트 방향 전환으로 추출하지 않는다. 주기 시간은 57/60이 아닌 56/60이다. cm↔m 변환과 모델 배율을 중복 적용하지 않는다.

칼집 허리 고정, 소켓, Mirror와 실제 게임 연결은 Claude 담당이다. 검토용 자체 칼·검집은 Hips의 기울기를 따라가며 실제 게임 부착 검수가 아니다. 승인 후 실제 360° 이동·가감속·전환·칼집 간섭·사이드뷰 회귀를 확인해야 한다.

## 파일과 출처

`pg_quarter_run_v3.blend`에는 편집 가능한 액션/NLA, 변경하지 않은 캐릭터 사본, 자체 #30/#31 칼·검집, 검토 카메라·조명과 패킹 텍스처가 있다. `pg_quarter_run_v3.fbx`에는 리그와 모션만 있다.

v2는 사용자가 제공한 `../pg-quarter-run-v1/jog_fwd_loop_anim_only.glb`를 관찰하고 현재 리그에 새 키프레임을 작성한 모션이다. v3는 그 자세 수정본이다. 참고 원본 곡선의 복사·리타깃은 없으며 참고 리그/액션도 산출물에 포함하지 않았다. 파일 메타데이터의 ActionForge/Quaternius·CC0-1.0 표기는 `reference_usage.json`에 기록했다.

- 참고 GLB SHA-256: `e8ea3b9f4aee193cda1c435f7149686340186d017d63d0b569c7c4029818f64d`
- 캐릭터 입력 GLB SHA-256: `d52a59d539983d7702ff6161f2702d96ac6433423a432ecb1f8900946686dd85`

캐릭터 메시·텍스처·가중치와 기존 v2 파일을 보존했다. 사용자 요청에 따라 v3 산출물을 로컬 커밋으로 보관한다. Unity 파일 수정·임포트·Issue 게시·push는 수행하지 않았다.

FBX는 60fps 타임라인에서 0.25프레임 간격(240Hz)으로 베이크했다. 재내보내기는 NLA extrapolation=`NOTHING`, strip 밖 **frame 0의 T pose**에서 시작하고 1~57의 NLA strip 하나를 내보낸다. 키 감소나 재압축 후 접지는 다시 검사한다.
