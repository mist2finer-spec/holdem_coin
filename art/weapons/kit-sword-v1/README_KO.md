## 디자인

검은 칼날·얇은 차가운 색의 날·어두운 자루·절제된 갈색 금속 부속의 분위기와 긴 발도용 비율을 유지했다. 새로운 곡률 구간과 단면을 직접 설계했다. 원작을 따라 찍은 정점·윤곽선은 없다.

달라진 부분은 작은 허리 모양의 팔각 코등이, 마름모가 반복되는 자루 감기, 세 줄의 금속 봉제 장식, 면을 나눈 끝마개, 별도의 짧은 칼날 고정쇠다. 넓고 화려한 판형 코등이는 피했다. 검집은 이번 납품에 포함하지 않는다.

출처: **자체 제작**. `build_original_sword.py`는 참조 메시·UV·텍스처를 읽지 않는다. Blender 5.3 MCP에서 새 정점과 UV, 색 아틀라스를 작성했다. 이미지 생성 도구는 등록되어 있으나 고정 C: 캐시와 G: 전용 저장 조건이 충돌하여 **실행 UNAVAILABLE(미실행)**. 이미지들은 실제 Blender 렌더다.

## 치수·원점·축

아래 현재 칼 측정값은 로컬 인계 전용이다. 공개 공유는 원본의 위치·해시 인덱스만 사용한다.

| 항목 | 현재 보이는 칼 | 새 칼 |
|---|---:|---:|
| 메시 길이, 축 방향 | 1.488132775 m | 1.488132849 m(FBX 재입력 측정) |
| 현재 프리팹 배율 | 0.6871183 | 동일 배율에서 비교·손 시안 |
| 위 배율에서 길이 | 1.022523262 m | 약 1.022523313 m |
| 쥐는 점에서 칼끝까지, 메시 단위 | 1.314718127 m | 1.314718246 m |
| 삼각형 | 보이는 칼 부분 3,244 | **492** |

길이 차이 약 0.000005%로 ±5% 조건 안이다. 현재 `.asset`에는 검집과 비표시 데이터도 있으므로 전체 bounds로 길이를 정하지 않았다. 프리팹의 Katana가 숨기는 검집 뼈 분기(49~56)를 제외하고 실제 인덱스가 참조하는 칼 부분을 측정했다.

- 기존 손잡이 쥐는 점: 원본 메시 좌표 약 **(0, 0, -0.600000) m**. `G_katana_ha_grip`의 inverse bind pose로 확인.
- 새 칼 피벗: **(0, 0, 0)**, 그립 기준. 새 FBX 정점은 뒤끝 Z=-0.173414603, 칼끝 Z=+1.314718246 m.
- FBX/Unity 기준 칼끝 **+Z**, 위 **+Y**, 두께 **X**. Blender 작업본은 칼끝 -Y, 위 +Z.
- 오브젝트 위치 0, 배율 1. FBX Y-up을 Blender Z-up으로 다시 읽을 때 importer가 X=+90°를 붙이는 것은 좌표 변환이다. **Unity에서 실제 import·축 검증은 미실행**이다.
- 기존 Katana는 skinned mesh와 0.6871183 배율을 사용한다. 새 파일은 그립 원점의 static mesh이므로, 기존 renderer에 mesh만 대입하는 방식으로 무조건 교체된다고 보장하지 않는다. Claude가 손 소켓 연결과 배율의 중복 적용 여부를 확인한다.

## 검증과 남은 일

**PASS — 실제 Blender 실행:** 새 메시 생성, 512² PNG 저장, FBX 출력 및 재입력, 원점·치수·+Z 방향, 재질 1개·UV 1개. non-manifold edge 0, 면적 0인 면 0, UV 0~1 범위 밖 0. FBX에는 요청한 새 칼 오브젝트만 있고, `.blend`에도 새 칼·새 텍스처만 있다.

**PASS — 작성자 시각 검토:** 정면·측면 같은 축척 비교, 원래의 검은 날 분위기, 자체 장식, 손잡이 위치와 착용 시안. 독립 검수나 사용자 승인과 다르다.

**FAIL — 세션 전체 Unity 변경 0:** MCP 연결을 위해 기존 Editor를 실행한 뒤 Beech 모델 4개의 `.meta`에서 `isReadable: 0 → 1`이 생겼다. 기존 `MountSundayModelImport.cs`의 자동 전처리 규칙과 Editor 재임포트 로그를 확인했다. 수동 Unity 파일 수정·MCP 쓰기·새 칼 import는 하지 않았다. 기존 변경 5파일 및 패키지 파일 2개의 SHA-256은 실행 전과 동일하다. 원상복구나 커밋은 수행하지 않았으며 Claude 검토 필요.

**UNAVAILABLE — 미실행/미승인:** Unity 실제 배치·공격·납도·Ember·Android, 사용자 미술 승인, director ACCEPT, GitHub CLAIM/DELIVER 게시, 커밋·push.
