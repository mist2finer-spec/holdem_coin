## 크기·피벗·축

- 단위: m. 오브젝트 위치·회전 0, 배율 1. 그립 기준 원점 `(0,0,0)`.
- native FBX: 칼끝 `+Z`, 칼등 `+Y`, 두께 `X`. Blender 저작 좌표는 `(x,-z,y)`, 즉 끝 방향 `-Y`이다.
- 몸체 길이 **1.14533335 m**, 현재 프리팹 배율 `0.6871183`에서 **0.78697950 m**. 참고 검집 길이와의 차이 약 `0.0000052%`로 ±5% 조건을 충족한다.
- 외부 범위 native FBX: X `-0.019~0.019`, Y `-0.0275~0.0820`, Z `0.1900~1.33533335` m. Y 범위는 곡률과 고리를 포함한다.
- 입구 native Z `0.190 m`, 내부 바닥 `1.328 m`. 수정된 칼의 고정쇠를 수용하도록 입구를 설계했다. 원작 단면을 복사하지 않았다.
- 296 정점 / **588 삼각형**, 재질 **1개**, 텍스처 **1장**. 중공 몸체와 끈 고리는 각기 닫힌 연결 요소다. 고리의 보이지 않는 받침은 몸체 벽에 겹쳐 고정되며 내부 칼 통로를 침범하지 않는다.

제안 연결점은 `Mirror/Scabbard/G_weapon_root/G_katana_saya_grip`이다. 기존 칼과 동일한 FBX 내보내기 규약을 썼으므로, 새 static 자식의 시작 설정은 position `(0,0,0)`, rotation `(0,0.7071068,0.7071068,0)`, scale `(1,1,1)`이다. 이 값은 현재 `KitSword_V1` 자식 설정과 좌표 변환을 근거로 한 **통합 시작값**이며, Unity 실행 검증을 완료했다는 뜻은 아니다. 기존 상위 배율을 중복 적용하지 않는다.

현재 Scabbard의 `saya1_scl`·`saya2_scl`은 배율 0인 가지다. 새 메시를 그 아래에 붙이지 않는다. 기존 추출 SkinnedMeshRenderer에 새 static mesh를 그대로 대입하는 방식이 아니라, Claude가 해당 그립에 부착하고 기존 추출 렌더러/참조 처리를 담당한다. 기존 애니메이션, 그립 트랜스폼, Mirror 방향은 유지하면서 납도·발도 자세를 검증해야 한다.

## 디자인·출처·검수 범위

**출처: 자체 제작.** 정점, 중공 단면, UV, 아틀라스 픽셀을 새로 저작했다. 참고 검집의 메시를 복사·축소·변형하거나 원작 텍스처를 재사용하지 않았다. 수정된 자체 칼의 단면을 수용하는 팔각 중공 구조, 짧은 입구 금속, 각진 외부 끈 고리, 자주색 띠와 끊어진 가는 선, 닫힌 다면 마개가 새 디자인이다.

Blender 재질은 Principled roughness 0.60 / metallic 0.14. PNG는 조명 영향 없이 아틀라스 색을 보여 주는 검토 렌더다. 게임의 셀 셰이더 연결과 모바일 표시 결과는 Claude의 통합 범위다.

- **PASS:** Blender 5.3 MCP 실제 저작·렌더·내보내기·재입력, 작성자 측면/단면 시각 검토.
- **UNAVAILABLE(미실행):** Unity 임포트·게임 납도/발도/공격 포즈·모바일 실행·독립 검수.
- **대기:** 사용자 미술 승인, 게임 반영, director ACCEPT. 현재 작업만으로 공용 빌드 해제를 선언하지 않는다.
